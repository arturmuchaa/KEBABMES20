# Okno druku — próba na komputerze biura z bizhubem

Przed wydaniem na trzy komputery. Każdy punkt: wynik (OK / błąd + opis), kto, kiedy.

| # | Sprawdzenie | Oczekiwane | Wynik |
|---|---|---|---|
| 1 | Druk dowolnego dokumentu | Otwiera się nasze okno druku, lista drukarek z Windows, domyślna zaznaczona | |
| 2 | Zasobniki | Lista z nazwami ze sterownika Konica (Zasobnik 1–4…); przy pierwszym wydruku wybrany zasobnik 1, czarno-biały | |
| 3 | Zmiana zasobnika | Kartka wychodzi z wybranego zasobnika (np. 3 – kolorowy papier) | |
| 4 | Kolor / czarno-biały, dwustronnie | Wydruk zgodny z wyborem | |
| 5 | „Więcej ustawień drukarki” | Opcje Konica (zszywanie, jakość…) widoczne i działają | |
| 6 | „Ustawienia drukarki…” | Otwiera oryginalne okno Konica; wybór wraca do naszego okna i jest użyty | |
| 7 | Kartki palet | Skala 1:1; QR skanuje się skanerem mroźni (ważenie palety przechodzi) | |
| 8 | WZ / CMR / HDI z serwera (Dokumenty, Papiery kursu) | Drukują się przez okno, bez zewnętrznego programu PDF | |
| 9 | Zapamiętanie | Po restarcie programu ten sam dokument ma te same ustawienia; inny dokument swoje | |
| 10 | Kolor zasobnika | Wpisany kolor widać na liście („Zasobnik 3 – zielone”), po restarcie też | |
| 11 | Rejestr | Po wydruku kartek przy palecie „wydrukowano … · login”; licznik palet bez kartki maleje | |
| 12 | Bez sieci do serwera | Druk przechodzi; po powrocie sieci wpis rejestru dochodzi (znacznik pojawia się) | |
| 13 | Błąd druku (drukarka wyłączona) | Czytelny komunikat + „Drukuj oknem systemowym” działa | |
| 14 | Druga drukarka (np. PDF Windows) | Wybór drukarki działa, ustawienia per drukarka | |
